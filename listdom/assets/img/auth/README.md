# Provider logos

These marks belong to their respective providers and are bundled for sign-in
buttons. Keep their original proportions and artwork.

- Google: https://developers.google.com/identity/branding-guidelines
  (`https://developers.google.com/static/identity/images/g-logo.png`).
- Yahoo: the compact Y! icon from Font Awesome Free 6.7.2 by Fonticons, Inc.,
  licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  [Original SVG](https://github.com/FortAwesome/Font-Awesome/blob/6.7.2/svgs/brands/yahoo.svg).
  The viewBox is tightened to the artwork and the fill is Yahoo purple (#6001d2).
- Microsoft: https://learn.microsoft.com/en-us/entra/identity-platform/howto-add-branding-in-apps
  (official Microsoft symbol SVG).
- Apple: the Apple mark path from the official Sign in with Apple SDK,
  `https://appleid.cdn-apple.com/appleauth/static/jsapi/appleid/1/en_US/appleid.auth.js`.
